# Pejman Habibiroudkenar

Personal robotics portfolio with Consultancy Services, Research, and Previous Projects sections.

## Preview

Open `index.html` in a browser, or serve the folder with `python3 -m http.server 8000`. No build step or external dependencies are required.

## Structure

- `index.html`: page content
- `assets/styles.css`: responsive styling
- `assets/app.js`: navigation, scroll effects, and publication filters
- `assets/images/`: images used by the page
- `assets/documents/`: CV and research-figure license

## GitHub Pages

To publish, select **Settings → Pages → Deploy from a branch**, then choose the default branch and `/ (root)`. Uploading this source alone does not enable Pages.

## Images and sources

Workshop and event photographs were supplied for this portfolio. The opening portrait is the earlier AI-restyled version approved by the owner (pejman-hero-restored.png, identical to the approved v7), restored from the existing asset. No new image generation was used for this restoration. The CHARMBot photograph comes from the [HIP–CERN presentation](https://pejman712.github.io/HIP-CERN-Talk-v2/) (`assets/img/p11-001.jpg`); its background was removed with a conventional image mask. Research figures come from [Non-Repetitive LiDAR Registration](https://github.com/Pejman712/Non_Repetetive_LiDAR_Registertion); the supplied Apache 2.0 license is included. Original research figures remain available alongside the styled section cover.

The page links to the supporting publications, datasets, and project demonstrations. No blanket license is granted for the personal photographs or other third-party material.
